# Interactive Visualization

Self-contained Three.js application — open directly in a web browser, no
server required.

| File | What it shows |
|---|---|
| `qsd_4simplex.html` | The QSD node as a 4-simplex: all 5 vertices and 10 edges of the K₅ skeleton, the K₄ tetrahedron after the γ₀-split, and the anchor. Rotate, zoom, and toggle the two views of the same object. |

*The v1.0 release shipped two further visualizations (a 4-block network and
a snap-mechanism animation). Both depicted structures that Phase 2 research
superseded — the inter-node lattice is the coordination-5 Bethe/{5,4}
structure, and the snap is the $2K_5 → 5K_2$ transition — so they are retired
from the current release (they remain in the v1.0 tag and Zenodo v1
record). Corrected dynamic visualizations are in preparation.*
